1. Mean Squarred Error (MSE)
- Average of the squared differences between actual values and prediction 
- strongly penalises big mistakes 

2. Mean Absolute Error 
- Average of the absolute differences between actual values and predictions 

3. Mean Absolute Percentage Error (MAPE)
- Average percentage error between prediction and actual value
- ON average, it is off by X%

4. Root Mean Squared Error (RMSE)
- Square root of MSE (brings error back to original units)
- Like MAE, but peanalises large error more
